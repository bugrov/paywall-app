# Состояние проекта

Журнал этапов. Обновляется в конце каждого этапа, до показа пользователю.

## Решения (действуют на весь проект)
- Концепт: №1 «Комета Кузя» (космос, тёмно-синий фон, оранжевая комета). Выбран пользователем 2026-10-12.
- Пакетный менеджер: npm. БД: Neon Postgres через Vercel Marketplace, без ORM.
- Стили: обычный SCSS (scoped) + БЭМ + миксины, `toRem()`. Tailwind пробовали (через `@apply`) и убрали
  по решению пользователя: stylelint-конфиг заточен под обычные стили. Nuxt UI и Pinia не используем.
- Git: всё в `main`, один коммит на этап, пуш только после ОК пользователя.
- Скиллы и правила лежат в репозитории (`.claude/skills`).

## Этап 2. Figma-макет - на проверке у пользователя
- Файл: https://www.figma.com/design/J3vsiNAENs7aYT5DENtZ5w (страница `Paywall`, fileKey `J3vsiNAENs7aYT5DENtZ5w`).
- Фреймы 390x844: Default (3:2), Purchasing (3:48), Offers loading (3:95), Error (3:137), Success (3:186).
  Варианты ширины Default: 360 (3:212) и 430 (3:258).
- Раскладка (Default): верхняя панель с кнопкой закрытия 44px; иллюстрация фиксированная 320x229 по
  центру (на 360 помещается без выхода за поля); заголовок Unbounded 700 24/120%
  по центру; подзаголовок Onest 400 16/145% (перенос после «планеты»); гибкий отступ; две карточки в ряд
  (gap 12, padding 14, радиус 20, минимум 112px); CTA 56px, радиус 18; ссылка «Восстановить покупки» 44px,
  Onest 14 с подчёркиванием. Юридической строки нет: её не было в задании.
- Выбранная карточка: фон paper, обводка comet 3px снаружи, бейдж mint «Выгода −48%», метка-галочка comet.
  Невыбранная: paper 7% + обводка lilac 50% 1.5px.
- Состояния: Purchasing (спиннер в CTA, карточки 50%), Offers loading (скелетоны, CTA неактивна),
  Error (баннер comet 14% + CTA «Повторить»), Success (галочка mint, CTA «Играть»).
- Осталось: пользователь проверяет макет и выдаёт доступ «Anyone with the link can view» (Share в Figma).
  Через MCP права доступа менять нельзя.
