# Состояние проекта

Журнал этапов. Обновляется в конце каждого этапа, до показа пользователю.

## Решения (действуют на весь проект)
- Концепт: №1 «Комета Кузя» (космос, тёмно-синий фон, оранжевая комета). Выбран пользователем 2026-10-12.
- Пакетный менеджер: npm. БД: Neon Postgres через Vercel Marketplace, без ORM.
- Стили: обычный SCSS (scoped) + БЭМ + миксины, `toRem()`. Tailwind пробовали (через `@apply`) и убрали
  по решению пользователя: stylelint-конфиг заточен под обычные стили. Nuxt UI и Pinia не используем.
- Git: всё в `main`, один коммит на этап, пуш только после ОК пользователя.
- Скиллы и правила лежат в репозитории (`.claude/skills`).

## Этап 0. Превью концептов - готово
- Сделано: HTML-страница с 10 концептами, опубликована приватным артефактом.
- Решение: выбран концепт №1.

## Этап 1. Каркас - на проверке у пользователя
- Сделано: Nuxt 4 + TS, SCSS с `toRem()` и миксинами, CSS-токены в `:root`, `@nuxt/fonts`, ESLint, Stylelint
  (конфиг пользователя без изменений), `nuxt typecheck`, скрипты `check`, заглушка страницы,
  `CLAUDE.md`, три скилла проекта, `.env.example`.
- Проверено: `npm run check` без ошибок, `npm run build` проходит, шрифты (cyrillic woff2) попали в сборку.
- Замечания: Node 22.15 ниже требуемого Nuxt 4.6 (`^22.21`), даёт предупреждение; `npm audit` показывает
  уязвимости в транзитивных dev-зависимостях, прод-зависимости проверим на этапе 5.
- Осталось: после ОК пользователя - `git init`, remote, коммит и пуш; перезагрузить плагины и скиллы.
